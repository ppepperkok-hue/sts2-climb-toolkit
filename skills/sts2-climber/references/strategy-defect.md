# Defect（故障机器人）策略

定位：A 级角色，机制大改——永久 Focus 叠加没了，别沿用一代思维。稳定路线是 0 费 Claw，球流上限高但慢。

## Claw 连发（S 级，最稳）

- 核心：Claw（0 费 3 伤，本场每打一张 Claw 全体 Claw 永久 +2 伤，指数成长）+ All for One（X 费：把弃牌堆所有 0 费牌拿回手）+ Feral（能力：每回合第一张 0 费攻击回到手牌）。
- 0 费家族：Claw、FTL、Beam Cell、Go for the Eyes、Momentum Strike、Scrape、Skim、Steam Barrier、Flash of Steel。
- 这套**不碰球**：Capacitor/球相关能力卡别拿。
- 遗物：Unceasing Top（手牌空就抽牌）、Sundial（每 10 次洗牌 +2 能量）。
- 升级优先：Feral（回手两张）、Claw。

## Synchronize + Shatter 爆发（A+ 级）

- 机制：四种球（闪电/冰霜/黑暗/玻璃）各充能一个后，Synchronize（本回合每种球 +2 Focus）一次 +8 Focus，再用 Shatter（全体 11 伤并释放所有球）。
- 前提：Capacitor（+2 球位，默认 3 位放不下 4 种）。
- 球多样性是硬要求，别堆单一球种。

## 闪电快攻（A+ 级，走廊怪最爽）

- Ball Lightning（7 伤+充闪电）、Zap、Tempest（X 费充 X 闪电）、Voltaic、Thunder（释放闪电全体伤）。
- 起手遗物 Cracked Core 每场白送一颗闪电，第一回合就有伤害。

## 冰霜龟缩（A 级，耐久）

- Glacier（6 格挡+2 冰霜）、Coolheaded（冰霜+抽1）、Chill（每敌一冰霜）、Capacitor + Defragment（+1 Focus）。
- 高 Focus 下每回合被动格挡；输出靠其它球或 Claw 补。
- 适合卡池差、需要保命的局。

## 黑暗核弹（A- 级，Boss 特化）

- 黑暗球随时间成长（每回合 +6+Focus），Darkness 充能、Multi-Cast（X 费释放 X 次）引爆，后期单发 200+。
- 短战斗没用，专打 Boss 和慢精英。

## 抓牌纪律

- 默认走 Claw；前期拿到 Synchronize + 球支持才转球流。
- 球位管理：充能顺序决定释放顺序，别把要留的球挤掉。
- 能量卡（TURBO、Double Energy、Supercritical、Charge Battery）和 Plasma 球解决大费卡问题。
